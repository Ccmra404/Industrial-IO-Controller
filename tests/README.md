# 测试与验证

本目录保存测试计划、测试步骤、原始记录、问题单关联和验证报告。

## 建议测试分类

- 上电与电源：输入范围、静态电流、纹波、启动和掉电行为。
- IO 功能：每种输入/输出类型的正常、边界和异常条件。
- 通信：连接、数据正确性、超时、断线和恢复。
- 保护功能：按设计规格验证过流、短路、反接、ESD/浪涌等项目。
- 环境与可靠性：按产品目标制定温升、环境和寿命测试。
- 回归测试：硬件或固件变更后复测受影响功能。

## 测试记录模板

每条记录至少包含：

- 测试编号、日期和执行人。
- 样机硬件版本、固件版本和配置。
- 测试设备及校准状态（适用时）。
- 接线图、测试条件和操作步骤。
- 预期结果、实际结果和原始数据。
- 结论：通过 / 失败 / 阻塞 / 未执行。
- 对应 Issue、整改提交和复测结果。

## 安全要求

测试前核对电压、电流、负载、隔离和接线条件。涉及危险电压、大电流或现场设备时，必须有经评审的测试方案和适当防护；不得仅凭本目录中的通用说明开展危险测试。
