# 硬件设计

本目录用于管理硬件设计源文件、设计说明和制造资料。

## 目录约定

- `eda/`：嘉立创 EDA 等工具的原生工程文件、原理图、PCB 和库文件。
- `manufacturing/`：按硬件版本归档的 BOM、Gerber、钻孔、坐标和装配资料。

## 提交要求

1. 优先提交完整、可编辑的 EDA 原生工程，而不只是导出的 PDF 或截图。
2. 每次硬件变更说明板卡版本、变更原因和影响范围。
3. 提交前检查 ERC、DRC、封装、网络、器件编号和关键电气规则。
4. 生产文件应从明确的工程版本导出，并记录工具版本和导出日期。
5. 不要把临时备份、缓存或个人临时文件当作正式设计版本。
6. 不要仅凭仿真或 ERC/DRC 通过就宣称实物设计已验证。

## 版本建议

硬件版本可采用 `HW-x.y` 或项目约定的编号。原理图、PCB、BOM、Gerber 和测试报告必须能够对应到同一硬件版本。
