# EDA 原生工程

将嘉立创 EDA 或其他 EDA 工具的**完整原生工程文件**放在本目录中。

建议每块 PCB 使用独立子目录，并保留工具生成的工程结构。例如：

```text
hardware/eda/
└── controller-board/
    ├── <EDA 原生工程文件>
    ├── schematic/
    └── README.md
```

每个工程建议附带说明：

- 板卡名称、硬件版本和当前状态。
- 使用的 EDA 软件及版本。
- 原理图、PCB 和库文件的入口。
- 关键设计约束与尚未解决的问题。
- ERC/DRC 检查结果及日期。

请勿只上传图片替代原生工程。仓库的 `.gitignore` 采用保守规则，不会按扩展名屏蔽常见 EDA 源文件；提交前仍需检查 Git 变更列表，确认没有缓存、临时文件或敏感资料。
