# EDA 原生工程

将嘉立创 EDA 或其他 EDA 工具的**完整原生工程文件**放在本目录中。

建议每块 PCB 使用独立子目录，并保留工具生成的工程结构。例如：

```text
hardware/eda/
└── controller-board/
    ├── <EDA 原生工程文件>
    ├── schematic/
    └── README.md
```

每个工程建议附带说明：

- 板卡名称、硬件版本和当前状态。
- 使用的 EDA 软件及版本。
- 原理图、PCB 和库文件的入口。
- 关键设计约束与尚未解决的问题。
- ERC/DRC 检查结果及日期。

> 本仓库仅公开方案与技术文档；原生 EDA 工程、原理图、PCB、网表快照及渲染图均保存在本地工作区（已在 `.gitignore` 屏蔽），不提交至 GitHub。
