# rs485-io-board（RS485 控制板）

6 路开关输入 / 12 路 24V 输出工业 IO 控制板，主控 **`STM32F103CBT6`**（LQFP-48，8MHz，3.3V）。

> 注：本目录仅在 GitHub 保留架构与方案说明文档；原生 EDA 工程、原理图、PCB、网表及渲染图均保存在本地工作区，不提交至公开仓库。

- **EDA 工具**：嘉立创EDA专业版（`82 × 82 mm` 双面布局、`175` 颗器件，全 `0805` 贴片阻容/LED + `3.81mm` 弯插闭口端子）
- **当前阶段**：原理图完成并经严格 DRC 核对（`errors: 0`、`SHOWDANDLING: 0`、`NETOBJECTONGRID: 0`）；`PCB1` 已完成 `82 × 82 mm` 双面摆件并通过碰撞/边距检查，待大电流铺铜与全板走线。

## 模块方案概览（2026-11-26）

| 模块 | 当前方案 |
|---|---|
| 主控 | `STM32F103CBT6`（8MHz HSE + 低电平复位 + `JP2` BOOT0 + `H3` SWD + `PA12` 心跳绿灯） |
| 电源架构 | 单路 24V：`U4` → `V24_IN` → `F2` 12A → `Q82 AOD4185` 理想二极管 → `OUT_24V`（`U57` 33V TVS）→ `SW5` → `F1` 1.5A → `LM2596S-5.0` (`SYS_5V`)；`TPS2113A`（`1kΩ` 0.5A 限流）双选 `SYS_5V`/`USB_5V` → `V5_LDO` → `AMS1117-3.3` (`MCU_3V3`)；全板共 `GND` |
| USB 串口 | `CH340K` 改 3.3V（`VCC`+`V3` 接 `MCU_3V3`），`USB_5V` 配 `1µF + 100nF` 滤波，经 `R550`/`R551`（`330Ω`）直连 `PA10`/`PA9` |
| 6 路开关输入 | 5V 光耦隔离输入（`SYS_5V → 1kΩ → 3.81mm 2P 端子 → LTV-846S → GND`，`MCU_3V3` 上拉；按 `PB5~PB9, PC13` 顺直排列，避开 JTAG） |
| 12 路输出 | `3.3V` 驱动 `LTV-846S`（`330Ω`）+ `AO3401A` P-MOS 驱动 `OUT_24V`（含 `SS34` 续流 + `BZT52C12` 栅极稳压，按 `PA11,PA8,PB15..12,PB1..0,PA7..4` 顺时针单调排列） |
| RS485 通信 | `MAX3485ESA`（3.3V），`R7/R8` `330Ω` 偏置 + `R9` `120Ω` 终端，连接 `USART3`（`PB10`/`PB11`）+ `PB2` 使能 + TTL 侧 TX/RX 绿灯 |
| 4 路 AD 采样 | `100kΩ`/`10kΩ`（`1/11`）分压 + `100nF` 滤波（`PA0~PA3`，支持 `0~24V`、满量程 `36.3V`） |
| 焊接与 BOM 精简 | 全部贴片阻容/灯统一为 `0805`；全板电阻合并为 `5` 种阻值（`10k/330/1k/100k/120Ω`）、贴片电容 `4` 种容值（`100nF/10µF/22pF/1µF`），电源红灯 + 通信运行绿灯 |
