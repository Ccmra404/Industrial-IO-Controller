# 固件

本目录用于管理控制器嵌入式固件。当前尚未指定 MCU、编译器、RTOS 或通信协议，因此不预设具体工程模板。

## 建议模块划分

后续可根据实际平台建立：

- `Core/`：启动、系统初始化和主流程。
- `Drivers/`：芯片外设及板级驱动。
- `BSP/`：板级支持包与引脚定义。
- `App/`：IO 业务逻辑、状态机和故障处理。
- `Protocol/`：通信协议实现。
- `Config/`：经过审查的默认配置模板。

## 开发要求

- 固定并记录 MCU、编译器和工具链版本。
- 引脚、时钟、外设配置集中管理，避免散落的硬编码。
- 对输入去抖、输出安全状态、超时和异常恢复定义明确行为。
- 关键接口和状态机提供测试或验证记录。
- 每个发布固件应关联硬件版本、源码提交和构建配置。
- 不提交设备密钥、生产密码或个人环境配置。

确定具体平台后，在此补充安装依赖、工程打开方式、构建命令、烧录方法和调试步骤。
