## 3. 2026-11-24 已做的电源修改（实时网络表读取）

USB 插座 USB2 Type-B：VBUS 接 `USB_5V`，D− 接 `UD-`，D+ 接 `UD+`，地接 `GND`。CH340K U45：VCC = `USB_5V`；TXD = `MCU_UART1_RX`；RXD = `MCU_UART1_TX`；DTR# = `DTR_COLD`；RTS# = `RTS#`；GND 接 GND。C19 / C20 从 USB_5V 至 GND；二者在当前网表的厂家型号字段为空，采购与规格须单独确认。

USB 静电防护：E1/E2 均为 RLSD32A051LC，C20884；E1 接 UD− 与 GND，E2 接 UD+ 与 GND。GND 是 USB 信号 / CH340 地，控制板 U5 MAX485 同样接此 GND。ESD 不是电气隔离。接口屏蔽壳与信号地的实际引脚关系需核对 Type-B 连接器数据表，不要凭符号猜测。

已移除 D16（原 USB_5V → SYS_5V）。新加 U3 TPS2113APWR（TI，立创 C130052，TSSOP-8）、R4 680Ω（0805W8F6800T5E，C17798）、C1 1µF / 50V X7R（CL21B105KBFNNNE，C28323）：

```text
USB_5V ──────────────────────────────> CH340 U45 VCC
   └──────────────> U3 IN1 (8)
SYS_5V ───────────> U3 IN2 (6)
U3 OUT (7) ───────> MCU_PRE5V ──> Q2 源极
U3 EN# (2)、VSNS (3)、GND (5) ──> GND
U3 ILIM (4) ── R4 680Ω ──> GND
U3 STAT (1) ── 悬空（有意不读取；尚未确认已加 NC 标记）
C1 ── MCU_PRE5V 与 GND 之间（无极性）
Q2 AO3401A：S = MCU_PRE5V，D = MCU_5V，G 接 Q3 漏极及 R5
MCU_5V ──> MCU U1 VCC、MAX485 U5 VCC，以及其他 MCU 侧电路
```

U3 的 VSNS 接地、EN# 接地时，根据手册真值表自动选择较高的有效输入，并非固定“系统电源优先”。R4 680Ω 使用手册近似公式 500/R，限流典型值约 0.74A，具体容差、负载和 USB 电流限制仍需验证；**不能把该典型值视为 USB 合规保护阈值**。Q2 电源输入、控制上拉 R5 47k、Q3 门极上拉 R12 130k，已由 SYS_5V 改为 MCU_PRE5V。C10 1µF 一端连 DTR_COLD，另一端连 Q3 门极及 R12；Q3 源极 GND、漏极控制 Q2 栅极。R13 1k 接 MCU_5V 至 GND，用于放电，正常工作持续消耗约 5mA（按 5V 近似）。Q2 下游 C17 为 10µF、C18 为 100nF，实际放电受电路负载及反灌影响。

原电源 U2 = LM2596S-5.0；FB = SYS_5V、ON#/OFF = GND；D1 SS34 为续流二极管（阴极开关节点，阳极 GND）；D2 SS34 为输入串联二极管（阳极输入、阴极 U2 输入）。这些只是网表事实，不构成整段电源设计已验证。

H1 四针：1 = H1_5V、2 = MCU_UART1_TX、3 = MCU_UART1_RX、4 = GND；D18 SS34 阳极 H1_5V、阴极 SYS_5V。也就是说外部烧录器供电目前仍给 SYS_5V，不是只给 MCU；此时需检查 LM2596 输出被外部供电的情况、负载电流、供电冲突及是否仍符合用户期望。之前用户倾向外部烧录手动冷启动，未完成最终电路确认。

U5 MAX485ESA：VCC = MCU_5V，GND = GND，RO = MCU_UART2_RX，DI = MCU_UART2_TX，RE# 与 DE = MCU_RS485_EN。此控制板的 MAX485 不是隔离收发器。USB 供电时 MAX485 也被供电；MCU 冷启动时与 MCU 一起断电。实际保证工作电压至少 4.75V，USB 线缆、U3/Q2 的压降和负载可能使电压不足，必须按实际输入范围及负载验证。

器件数据：<https://www.ti.com/lit/ds/symlink/tps2113a.pdf>；<https://www.stcmicro.com/datasheet/STC12C5A60S2-en.pdf>；<https://ez.analog.com/interface-isolation/a/documents/c/max485esa-faq/DO17773/what-is-the-minimum-supply-voltage-for-the-max485>。

## 4. 最关键的未解决问题（按当前目标排序）

1. **12 路输出的反向供电**：目前以 R518 / U184 第一路为例，`SYS_5V -> R518 680Ω -> 光耦输入 LED -> MCU P00`，其他 11 路存在同类结构。Q2 断 MCU_5V 时 SYS_5V 可能仍在，通过 IO 的潜在注入路径使 MCU 电源降不下去；先核对 STC 实际 I/O 结构和可能注入，之后可评估将全部 12 路限流电阻的供电端改为 MCU_5V，并核算上电 / 工作电流、光耦驱动及负载。现阶段只是待验证风险，不要写成已测量故障。
2. **串口回灌**：U45 TXD 直接连 MCU_UART1_RX，MCU 断电而 CH340 保持供电时，可能从 MCU 引脚注入；反向情况（系统供电、USB 没插，CH340 不供电）也需检查 CH340 输入 / MCU TX 互相影响。H1 外部烧录器的 TX 也须分析。串电阻只能限制电流，不能单独保证阻断反灌；选有断电保护的缓冲 / 隔离，或其他经数据手册验证的方式。<https://www.ti.com/document-viewer/lit/html/SSZTAP0>
3. **ADC 和外部信号**：ADC 外部输入可能在 MCU 断电时仍有电；D21–D24 BAT54S 上钳位现在接 SYS_5V、下钳位 AGND，AGND 通过 R3 0Ω 接 GND。须分析外部信号电压范围、钳位作用、关机时注入与供电倒灌。不要未经分析只改二极管或宣称安全。
4. **DTR 冷启动时序**：U3 为电源来源选择，真正冷启动由 Q2/Q3/C10/DTR_COLD 产生。先确认实际 STC 下载软件与 CH340 驱动在点击下载、打开 / 关闭串口时对 DTR 的电平、极性和脉宽，分析 Q3 默认上拉与 C10 耦合的实际开关方向、可能误触发及 MCU_5V 放电时间；测电源波形、串口通信和下载成功率。不能假设所有烧录软件都控制 DTR。
5. **电源/反灌与压降边界**：只 USB、只 SYS、双电源、外部 H1 供电 / 断电、USB 拔插、MCU 切断、外部 24V 存在等状态逐一画路径；U3 对来源具备反向阻断，但 Q2 有体二极管，不具备单独双向隔离能力。核实 U3 供电选择、R4 限流、USB 上电电容与电脑可提供电流、U3 输入近端去耦以及 MAX485 ≥4.75V；不要给工程贴“已解决全部反灌”。
6. **其他电源域**：隔离输入输出涉及 +24V / 24GND，检查全部外部端口和驱动对 5V、GND 的影响；不要把 24GND 或多个地直接短接来“解决”问题。此前外部板实测 D4 移除后反灌消失，是另一张历史电路，不能等同于当前问题。
7. 近期新器件和线只做了网表 + `sch_Document.save()` 返回 true 的确认，**没有验证 PCB 更新、ERC、实物上电、示波器或编程**。需要结合当前最新工程重新验证，特别是 U3/R4/C1 元件库引用和封装，用户曾碰到保存异常。

### 8.2 电源

- 24V 两个来源：U56 外接（EXT_24V/24GND）、U4 板上 DC（正极经 SW5→F1→SYS_24V，**负极接 GND**）。JP1 三针（1=EXT_24V、2=SEL_24V、3=SYS_24V）二选一 → F2 → D15 SS34 防反 → OUT_24V，U57 SMBJ33A TVS。
- LM2596S-5.0：SYS_24V → D2 防反 → U2 → SYS_5V（SW4=33µH 电感；LED1+R2 指示灯）。
- 5V 切换：USB_5V 与 SYS_5V → U3 TPS2113APWR（EN#/VSNS 接地=自动选高）→ MCU_PRE5V；R4 680Ω 设 ILIM≈0.74A（理论值）。
- 冷启动：MCU_PRE5V → Q2(AO3401A P-MOS) → MCU_5V；Q3(AO3400A N-MOS) 默认拉低 Q2 栅极=常通；R5 47K/R12 130K/C10 1µF；CH340 DTR# → C10 耦合脉冲 → 瞬断 Q3 → Q2 断 → MCU 掉电（R13 1K 放电）→ 恢复 = 自动冷启动。

### 8.3 USB 与烧录

- USB Type-B + E1/E2（RLSD32A051LC）ESD；CH340K 由 USB_5V 供电；TXD/RXD 各串 2.2K（R550/R551）到 MCU_RXD/MCU_TXD。
- H1 四针外部烧录座共享同一串口（经同一组串阻），D18 SS34 把 H1_5V 单向供到 SYS_5V；两个烧录器不同时接。RTS# 悬空未用。

### 8.4 RS485

- U5 MAX485ESA（MCU_5V 供电，与 MCU 同断电）；RE#/DE 共用 MCU_RS485_EN（R10 10K 下拉=默认收）；U6 三针端子 GND/A1/B1；D17 SM712 TVS；R7/R8 1K 失效保护偏置；R9 120Ω 终端电阻经 H2 跳线可选。

### 8.5 12 路输入（2026-11-25 重画完成，页面 452c4ed9fd5a2d33）

### 8.6 12 路输出

- 每路：MCU IO（P00-P07、P22-P25）→ 光耦 LED 阴极；阳极经 680Ω（R500 等）接 MCU_5V（已改，防 SYS_5V 反灌）。
- 输出侧：光耦晶体管拉低 P-MOS Q70-Q81（AO3401A）栅极 → OUT_x = OUT_24V；R501 等 10K 上拉栅极（默认关）；D100 等 BZT52C12 12V 钳 VGS；D101 SS34 在 OUT_24V 与 OUT4 之间（**方向待复核**）。

### 8.7 AD 采样（当前 4 路全电压）

- 每路：DG305 端子（ADC_INx + AGND）→ 电阻网络 → 100nF → BAT54S（下钳 AGND/上钳 MCU_5V）→ MCU_ADC1-4；AGND 经 R3 0Ω 接 GND。
- **疑似 bug**：100K 现在并联在输入到 AGND、4.7K 才是串到 ADC 的那只 → 分压比≈0.95，24V 会直进 ADC。应为 100K 串入、4.7K 下拉（24V→约1.1V）。此接法继承自原图，未改。

### 8.8 已知问题 / 待决策（最新）

1. **输出负载回路**：OUT_24V 选"板上 24V"时负极是 GND（U4 负端），而输出端子回流是 24GND，24GND 与 GND 全工程零连接 → 选板上 24V 时负载无回路。修法待定：外接专用 / 24GND-GND 加 0Ω / 端子改回流端。
2. **AD 分压电阻疑似接反**（见 8.7）。
3. **12 路输出拟改为带 12 路继电器**（老板要求）：计划维持 MOS 链，加 24V 线圈继电器（倾向 SRD-24VDC-SL-C），端子改干触点 COM/NO(/NC)，线圈加续流二极管（D101 方向正好要翻）。此改动同时消解问题 1。
4. **12 路输入拟支持干接点**（老板要求"两边一短接就是开关信号"）：需每路加一只上拉电阻 OUT_24V→EXT_INx（可用 2.4K 0603），短接即成回路；有源 12V/24V 信号照样兼容；5V 以下电流偏弱。
5. F2 保险丝规格未定（F1=BSMD2920-150 即 1.5A）；电流采样（TP181A3 200V/V + 2mΩ 分流，外部 20A/峰值 25A）讨论过未落图；C19/C20、C2、R1 器件厂家型号属性为空。
