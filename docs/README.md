# 项目文档

本目录保存需求、系统方案、接口定义、设计决策和使用说明。

建议文档按以下原则维护：

- 每项需求使用唯一编号，并给出验收条件。
- 重要设计决策记录背景、备选方案、结论和日期。
- 参数必须注明单位、适用条件、来源和版本。
- 区分“计划值”“计算值”“器件额定值”和“实测值”。
- 实测数据应记录仪器、测试条件、样机版本和结果。
- 变更规格时同步检查硬件、固件、测试和生产文档。

## 建议目录

- `specifications/`：产品需求、系统规格、电气参数和接口定义。
- 后续可按实际需要增加 `architecture/`、`decisions/`、`user-guide/` 等目录。
